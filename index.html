Plain meanings for words you'll see across this plan. No need to memorize them — come back here any time.

Level (or "Tier")
How much AI is trusted to work on its own, from 1 (a person checks every step) to 4 (AI runs approved routines with no one watching in real time).
Approval point (or "gate")
A checkpoint where work must be signed off before it moves on — by a fixed rule, a second AI check, or a person.
One person in charge (or "DRI")
One named owner is accountable for a result, instead of a group deciding by committee.
Second AI check (or "adversarial pass")
A second, independent AI reviews the first AI's work before it reaches a customer.
Playbook (or "canon")
The small set of official documents — answers, rules, procedures — that AI reads before doing any task.
Shared memory (or "context layer")
One searchable place holding your records, documents and decisions, which every tool and AI step can read from.
Accuracy test (or "eval")
An automatic check that keeps confirming the AI is still getting things right, the way a test drive checks a car.
Summarizing agent (or "distillation")
An AI that turns a large pile of calls, tickets and notes into a short, useful summary.
Build-and-test pipeline (or "CI")
The automatic process that checks and assembles software every time it changes, before it goes live.
Direct tool connection (or "connector"/"MCP")
A link that lets an AI tool read from and update another app directly, such as your CRM or support desk.
Company-wide safety rules (or "managed settings")
Guardrails set once, centrally, that no individual AI session can turn off or bypass.
Spending limit (or "spend envelope")
A cap agreed in advance so AI costs never creep up unnoticed.
